# 🪙 TIPxSPLIT — Tip Calculator

A clean, responsive tip calculator built for the Dev Weekends Fellowship 2026 assessment.

🔗 **Repo:** https://github.com/mashwani3033/TIPxSPLIT-tip_calculator.git

## How to Run

No installations. No build steps.

1. Clone the repository
   ```bash
   git clone https://github.com/mashwani3033/TIPxSPLIT-tip_calculator.git
   ```
2. Open `index.html` in any browser

That's it.

## File Structure

```
├── index.html   → Website structure
├── style.css    → Styling and theme
├── script.js    → All logic
├── README.md    → This file
└── ANSWERS.md   → Assessment questions
```

## Features

- Live calculation as you type — no button needed
- 7 currencies: Rs, $, €, £, ¥, AED, SAR
- Tip presets (10% / 15% / 20%) + custom input
- Inline validation with error messages
- Dark / Light mode toggle
- Per-person copy to clipboard
- Responsive — works on mobile and desktop
